使用方式

# 默认启动（端口 3000，目录 ./public）
node server.js

# 自定义端口和目录
node server.js --port 8080 --root ./dist

# 禁用缓存和目录列表
node server.js --no-cache --no-listing

# 查看帮助
node server.js --help
