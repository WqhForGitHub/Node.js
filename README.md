# 一、全局 API

这部分是挂载在全局作用域的 API，在任何代码中都可以直接调用，主要包含：

## 核心全局函数

- 定时器：`setTimeout()`、`setInterval()`、`setImmediate()`、`clearTimeout()`、`clearInterval()`、`clearImmediate()`
- 网络与编码：`fetch()`、`structuredClone()`、`btoa()`、`atob()`
- 微任务调度：`queueMicrotask()`

## 核心全局对象

- `globalThis` / `global`：全局作用域根对象
- `process`：进程信息与控制对象（包含上百个属性、方法、事件）
- `console`：控制台输出对象
- `Buffer`块加载：二进制缓冲区类
- `AbortController` / `AbortSignal`：异步取消控制器
- `TextEncoder` / `TextDecoder`：文本编解码器
- `URL` / `URLSearchParams`：标准 URL 处理对象
- `WebAssembly`：WebAssembly 运行时对象

## CommonJS 模块专属全局变量

- `__dirname`：当前文件所在目录路径
- `__filename`：当前文件的完整绝对路径
- `require()` / `module` / `exports`：模与导出变量

# 二、核心内置模块 API

## 1. 基础工具类

| 模块名           | 功能说明                   | 核心 API 规模                                         |
| ---------------- | -------------------------- | ----------------------------------------------------- |
| `assert`         | 断言测试，用于代码逻辑校验 | 20+ 个断言方法（equal、deepEqual、throws 等）         |
| `util`           | 通用工具函数库             | 30+ 个工具方法（类型判断、继承、promisify、格式化等） |
| `events`         | 事件触发器基类             | EventEmitter 核心类，所有流、网络模块都继承它         |
| `buffer`         | 二进制数据处理             | Buffer 类，包含数十个二进制操作方法                   |
| `string_decoder` | 缓冲区字符串解码           | StringDecoder 类，解决 Buffer 转字符串的乱码问题      |
| `querystring`    | URL 查询字符串解析         | parse、stringify、escape、unescape 核心方法           |
| `url`            | 旧版 URL 解析 API          | 传统 URL 解析与格式化（已逐步被全局 URL 替代）        |
| `punycode`       | 国际 化域名编码            | Punycode 域名编解码方法                               |
| `path`           | 文件路径处理               | 20+ 个方法（路径拼接、解析、规范化、相对路径计算等）  |

## 2. 文件与 IO 类

| 模块名        | 功能说明           | 核心 API 规模                                                  |
| ------------- | ------------------ | -------------------------------------------------------------- |
| `fs`          | 文件系统操作       | 150+ 个方法（文件读写、目录操作、权限管理，同步 + 异步双版本） |
| `fs/promises` | Promise 版文件系统 | 基于 Promise 的 fs API 集合，支持 async/await                  |
| `stream`      | 流操作基类         | Readable、Writable、Duplex、Transform 等核心流类               |
| `readline`    | 逐行读取输入       | 逐行读取流、命令行交互 API                                     |
| `tty`         | 终端设备交互       | 终端判断、终端流控制 API                                       |

# 三、原生插件 API

这是用于开发 C/C++ 原生扩展的跨版本稳定 API，独立于 JavaScript 层 API，包含约 80+ 个核心 C 接口，主要分为：

- 对象操作：创建 JS 对象、读写属性、类型判断
- 内存管理：引用计数、缓冲区管理、生命周期控制
- 异步封装：异步工作线程、回调函数封装
- 类与函数：将原生逻辑封装为 JS 函数和类
