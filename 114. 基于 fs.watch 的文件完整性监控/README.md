# 114. 基于 fs.watch 的文件完整性监控

对目录做完整性监控：维护"每个文件 size + mtime + sha1"指纹快照，`fs.watch` 事件触发（带 200ms 防抖）后重新扫一遍并对比，输出新增/删除/修改/元数据变更事件。

## 运行

```bash
npx ts-node watch.ts ./testdir
# 另一个终端在 ./testdir 内增删改文件
```

## 要点

- `fs.watch` 在不同系统上行为不一，加 200ms 防抖合并连续事件后再重新快照。
- 用 SHA1 区分真正内容变化与仅 mtime 变化。
- 启动时先快照 `prev`，后续每次事件再快照对比得到增/删/改。
